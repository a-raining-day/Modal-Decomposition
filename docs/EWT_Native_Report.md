| amfm | **1.028e-02** | 9.7e-20 | 4.100e-01 | 3.7e-18 | native(40×) |
| white | **1.082e-01** | 1.7e-18 | 1.678e-01 | 2.9e-17 | native |

- native 与 adapter 的**重构恒精确**(残差都按库内契约定:「`S − ΣIMFs`」); ewtpy 的**原始约定**(末带当残差)不满足这一条, 其偏差即上表 "ewtpy 带和" 列。
- 带和保真 **6 优于 / 2 略逊**(dc_trend +8.8%、bearing +4.9%, 同量级)。修改前(固定 γ=0.15)是 **1 优于 / 7 落后**(§2.2)。

### 2.1 根因分析: `Σ H` 与 `Σ H²`(直接测滤波器组)

先说清两个量的含义: 理想 Meyer 滤波器组满足**能量型紧框架** `Σ_i H_i²(ω) ≡ 1`; 而幅度和 `Σ_i H_i` 在任一互补过渡带中点必然等于 `√2`(即 `sin²+cos²=1` 处的 `sin+cos`), 所以"`max ΣH = 1.4142`"是**正常现象**, 不是缺陷。**判据只能看 `ΣH²`**。

**关键修正**: 用 `max ΣH²` 判紧框架是无效的 —— 任何带在通带内都取 1, 于是 `max ΣH² ≡ 1.000` 对谁都不假。必须看 `max|ΣH²−1|` 与**破缺频点占比**:

| 信号 | native(现状: auto γ + 顶部拉平) | native(旧默认 0.15) | ewtpy |
|---|---|---|---|
| multitone | **2.2e-16 / 0.0% / 1.00** | 0.703 / 15.9% / 0.50 | 0.499 / **33.8%** / 0.50 |
| close_tones | **2.2e-16 / 0.0% / 1.00** | 0.770 / 16.5% / 0.50 | 0.498 / **22.8%** / 0.50 |
| chirp | **2.2e-16 / 0.0% / 1.00** | **2.149** / **27.8%** / 0.50 | 0.449 / 0.8% / 0.55 |
| amfm | **2.2e-16 / 0.0% / 1.00** | 0.500 / 8.3% / 0.50 | 0.499 / **29.5%** / 0.50 |
| white | **2.2e-16 / 0.0% / 1.00** | 0.002 / 4.2% / 1.00 | 0.498 / **25.0%** / 0.50 |
| dc_trend | **2.2e-16 / 0.0% / 1.00** | 0.500 / 14.1% / 0.50 | 0.498 / 17.7% / 0.50 |
| bearing | **2.2e-16 / 0.0% / 1.00** | 0.945 / **39.5%** / 0.50 | 0.482 / 2.2% / 0.52 |
| spike | **2.2e-16 / 0.0% / 1.00** | 0.009 / 5.5% / 1.00 | 0.498 / **15.9%** / 0.50 |

(每格 = `max|ΣH²−1|` / 破缺频点占比 / Nyquist 频点处的 `ΣH²`; native 现状下 `min ΣH = 1.0000`、`max ΣH = 1.4142`。)

三条结论(都与直觉相反, 但可复核):

1. **native 现在是全轴严格紧框架**: 8 条信号的 `max|ΣH²−1|` 均为 **2.2e-16**(机器精度), 破缺频点 0 个, 连 Nyquist 频点也是 1.00 —— 两个关键修复(auto γ + 最高带拉平)共同作用的结果。
2. **固定 γ=0.15 是真正的缺陷来源**: 边界聚拢时过渡带互相叠加, chirp 上 `ΣH²` 冲到 **3.149**(同一频段被 3 条带重复计入), 破缺占比最高 39.5%。这正是修改前"带和误差普遍偏大"的主因。
3. **ewtpy 并不是紧框架**: 破缺占比 2.2%–33.8%, `max|ΣH²−1| ≈ 0.45–0.50`。机制是它的 γ 常被**上端约束** `(Nyquist−w_last)/(Nyquist+w_last)` 顶住(其边界分布更散), 使最后一个频带的通带塌缩, 从 `(1+γ)w_last` 到 Nyquist 的整段(实测占轴长 22%–34%)成为未被补偿的过渡带, 频谱高端被系统性压低。native 用**完全相同**的 γ 公式, 但「最高带拉平」使该半条过渡带不再存在, 故同一约束不再产生破缺。

> 注: 上一版报告曾按 `max ΣH²` 记下"ewtpy 恒保 `ΣH²≡1`、我们破缺" —— 该结论**已作废**, 正确结论是上表。

### 2.2 `band_factor="auto"`: 从"落后"到"反超"的机制与实测

γ 的解析规则(`_resolve_band_factor`): 算子把边界 `w` 的过渡带放在 `[(1−γ)w, (1+γ)w]`, 相邻边界不交叠要求

```
γ ≤ min( min_i (w_{i+1}−w_i)/(w_{i+1}+w_i) ,  (Nyquist − w_last)/(Nyquist + w_last) ) × (1 − 1/n_bins)
```

即 ewtpy 的同一公式(比值与频率单位无关), 末尾的 `(1−1/n_bins)` 是"严格小于"的安全余量。无内部边界(单频带)时退回 0.15。

**同一组边界下, 只换 γ 的效果**(N=2048, K=5):

### 2.3 最高带拉平到 Nyquist(已启用, §1 第 7 项)

修改前的残余缺陷是"最高带在 Nyquist 处还有一条过渡带, 而 Nyquist 之上没有频带能补偿它"(单边谱里不存在), 于是谱尾 `ΣH²` 掉到 0.5 且高频端被系统性压低 —— 破缺频点占轴长 0.6%–19.1%。三种构法实测(a=仅 auto γ; b=只用内部约束定 γ + 顶部拉平; c=**保持 auto γ** + 顶部拉平, 即最高带取 `w1 = Nyquist/(1−γ)`):

| 信号 | a 破缺频点 / 带和误差 | b | **c(= 现状)** |
|---|---|---|---|
| multitone | 57 / 0.0494 | 0 / 0.0494 | **0 / 0.0494** |
| close_tones | 53 / 0.0258 | 0 / 0.0258 | **0 / 0.0258** |
| chirp | 6 / 0.0340 | 0 / 0.0329 | **0 / 0.0329** |
| amfm | 108 / 0.0103 | 0 / 0.0118 | **0 / 0.0103** |
| white | 56 / 0.1099 | 0 / 0.1568 | **0 / 0.1082** |
| dc_trend | 196 / 0.0452 | 0 / 0.0452 | **0 / 0.0452** |
| bearing | 44 / 0.0981 | 0 / 0.0974 | **0 / 0.0974** |

## 3. §2 频带划分质量(纯音能量按带分配)

`capture` = 单个频带能吃下的该纯音能量的最大占比(用 `H_i(f)²` 做与实现无关的分配); `覆盖带数` = 占比 > 1% 的带数。

| 信号 | 方法 | 最小 capture | 平均 capture | 平均覆盖带数 |
|---|---|---:|---:|---:|
| multitone | **native** | **0.9674** | **0.9889** | 1.67 |
| multitone | ewtpy / adapter | 0.5399 | 0.8460 | 1.33 |
| close_tones | native | 0.9852 | 0.9906 | 1.00 |
| close_tones | **ewtpy** | **0.9987** | **0.9991** | 1.00 |
| bearing | native | 0.9946 | 0.9972 | 1.00 |
| bearing | **ewtpy** | **0.9992** | **0.9993** | 1.00 |

- multitone 上 native 明显更好(0.967 vs 0.540): 我们取"前 K 大峰 + 相邻峰中点", 三个音各落进独立频带; ewtpy 的平滑谱在这条信号上多检峰, 把某个音劈到两带。
- close_tones / bearing 上 ewtpy 仍略好(0.999 vs 0.985/0.995)。**bearing 的 2.00 覆盖带数已消失**(auto γ 后其音被单带吃下, 0.9767 → 0.9946), 剩余差距是"边界贴得不够准", 不是"分错带"。

## 4. §3 边界质量(最近匹配距离 / 漏检 / 多检 / 噪声稳定性)

理想边界 = 相邻音中点; 匹配容差 = 最小音间距的 25%。

| 信号 | 方法 | 平均匹配距离 Hz | 漏检 | 多检 | 稳定性(std) Hz | 检测到的内部边界 (Hz) |
|---|---|---:|---:|---:|---:|---|
| multitone | native | 1.46 | 0 | 2 | **1.06** | [46.9, 52.7, 102.8, 234.9] |
| multitone | ewtpy | **0.96** | 0 | 2 | 9.89 | [18.3, 43.5, 100.8, 236.1] |
| close_tones | **native** | **0.19** | 0 | 3 | **1.07** | [34.2, 38.1, 45.4, 59.8] |
| close_tones | ewtpy | 0.79 | 0 | 3 | 1.36 | [9.5, 21.2, 37.1, 60.8] |
| bearing | ewtpy | **25.05** | 0 | 3 | **0.12** | [137.5, 275.1, 288.3, 313.7] |
| bearing | native | 99.95 | 1 | 4 | 0.96 | [262.5, 287.4, 325.0, 362.5] |

- **稳定性**: native 在多音信号上明显更稳(1.06 vs 9.89 Hz) —— 我们不做谱平滑, 峰位不会被平滑核拖走; bearing 上 ewtpy 更稳(0.12 vs 0.96)。
- bearing(300 Hz 载波 + 25 Hz 冲击调制)是 native 最弱的一例: 谱上是一族边带, 取前 5 大峰会把边界铺进边带群(漏检 1 条), 而 ewtpy 的平滑把边带群并成一个支撑。这正是 §8 路线 2 要补的"谱平滑"。

## 6. §5 预处理分支的可测增益

### 5.1 DC / 趋势(信号 = 5.0 + 0.8·sin40 + 0.02·坡度 + 0.2·噪声)

| pre_deal | IMF0 均值 | 残差(vs 原始) | 残差(vs 预处理) | 低频带能量占比 |
|---|---:|---:|---:|---:|
| None | 5.0168 | **0.0038** | 0.0038 | 0.9865 |
| `no-dc` | **0.0000** | 0.9931 | 0.0324 | 0.0146 |
| `no-trend` | **0.0011** | 0.9929 | **0.0242** | **0.0090** |
| `no-dc`+`no-trend` | 0.0011 | 0.9929 | **0.0242** | **0.0090** |

—— 低通带里 DC/趋势占比从 **98.7% → 0.9%**, 这正是这两个分支的用途。两列残差**分母不同**(前者以**原始**信号、后者以**预处理后**信号为基准), 故数值不可直接比较; 真正说明问题的是末列"低频带能量占比"与 IMF0 均值。`残差(vs 原始)` 变大是**定义使然**: 去掉的直流/趋势按契约并入 `Res`, 以保住 `reconstruct()==原始输入`。

### 5.2 强噪下的边界稳定性(multitone + σ=1.0, 8 次实现)

| pre_deal | 平均匹配距离 Hz | 稳定性(std) Hz |
|---|---:|---:|
| None | 5.79 | 42.80 |
| `Slepian-Optimize` | **4.45** | 49.04 |
| `no-trend`+`Slepian-Optimize` | **4.44** | 52.43 |

—— 多锥估计让平均匹配距离改善 ~23%(5.79→4.45), 稳定性未见改善。**收益温和, 不宜默认开启**。

### 5.3 加窗对边界振铃的影响(chirp, 端点 2% 与内部峰值比)

| pre_deal | 平均振铃比(越小越好) | 重构(vs 原始) |
|---|---:|---:|
| None | 0.6611 | 3.5e-19 |
| `window`(hann) | **0.0008** | 2.5e-17 |
| `no-trend`+`window` | **0.0008** | 2.5e-17 |

—— **加窗把端点振铃压低约 830×**, 且重构仍精确(损失按契约进 `Res`)。这是最确定的收益项。

### 5.4 幅度谱平滑(`Smooth`, 新增分支, 默认关闭)

动机: 报告里"仍略逊"的那类指标(边界贴合度、capture)正是 ewtpy 靠 `reg='average', lengthFilter=10` 拿到的。实现方式与代价实测如下(N=2048, fs=1000, K=5, `mirror=False`; 边界检测轴 bin = 0.488 Hz, 故 `smooth_width=5` = 2.44 Hz = ewtpy 默认窗的等效宽度):

| 信号 | 配置 | 匹配距离 Hz | capture | 带和误差 | 稳定性 Hz | 耗时 ms |
|---|---|---:|---:|---:|---:|---:|
| multitone | 不平滑(现状) | 1.46 | 0.9674 | 0.0494 | **0.67** | 0.8 |
| multitone | `Smooth` box,5 | **0.14** | 0.9912 | 0.0213 | 2.42 | 0.8 |
| multitone | `Smooth` box,11 | 0.22 | 0.9948 | **0.0175** | 9.66 | 0.8 |
| multitone | `Smooth` gau,5 | **0.14** | **0.9963** | 0.0182 | 10.99 | 0.8 |
| multitone | 对照: `scale-space`(不平滑) | 12.68 | 0.9992 | 0.0074 | 6.30 | 6.1 |
| close_tones | 不平滑(现状) | 0.19 | 0.9852 | 0.0258 | 0.00 | 0.8 |
| close_tones | `Smooth` box,5 | **0.06** | 0.9890 | 0.0279 | 0.00 | 1.0 |
| close_tones | `Smooth` box,11 | 0.30 | 0.9933 | **0.0073** | 0.00 | 0.8 |
| close_tones | `Smooth` gau,5 | **0.06** | **0.9939** | 0.0174 | 0.00 | 0.9 |
| close_tones | 对照: `scale-space` | 60.00 | 0.9998 | 0.0041 | 0.00 | 5.7 |
| bearing | 不平滑(现状) | 99.95 | 0.9946 | 0.0974 | 0.00 | 0.8 |
| bearing | `Smooth` box,5 | 75.05 | 0.9926 | **0.0258** | 0.00 | 0.8 |
| bearing | `Smooth` box,11 | 124.61 | 0.9930 | 0.0865 | 0.00 | 0.8 |
| bearing | `Smooth` gau,5 | **74.80** | 0.9925 | 0.0261 | 0.00 | 0.8 |
| bearing | 对照: `scale-space` | **54.59** | **0.9982** | 0.1048 | 0.00 | 5.0 |

读数:

1. **收益确实落在"仍略逊"的两项上**: 匹配距离 1.46 → 0.14 Hz(multitone)、99.95 → 75.05 Hz(bearing), capture 0.9674 → 0.9912(multitone)、0.9852 → 0.9890(close_tones), 带和误差几乎腰斩(0.0494→0.0213、0.0974→0.0258)。**代价不到 1 ms**。
2. **代价是稳定性**: multitone 的噪声抖动 `0.67 → 2.42 (box,5) → 9.66 (box,11) → 10.99 (gau,5)` Hz, 最多差 16×, 已被推到 ewtpy 的水平(9.89 Hz, §4)—— 而稳定性正是我们领先 9× 的那一项。**这就是它必须默认关闭、按需开启的原因**(ewtpy 的不稳定同源)。
3. **它修不掉 bearing 的漏检**(仍 miss 1), 那只有 `scale-space` 能修(miss 0、capture 0.9982, 但慢 6×、抖动 32 Hz)。
4. **三者互补而非重复**: `maximum` = 最稳;`maximum`+`Smooth` = 快且准、怕噪;`scale-space` = 最准且无漏检、慢且抖。
5. `close_tones` / `bearing` 的稳定性指标在本测试里饱和(全 0), 该列只在 multitone 上有区分度。

用法: `EWT(num_imfs=5, pre_deal="Smooth")`, 或与多锥组合 `pre_deal=["Slepian-Optimize", "Smooth"]`(按 canonical 顺序施加, 与传入顺序无关); 参数 `smooth_kind` / `smooth_width`。**不传 `pre_deal` 时结果与之前逐位一致**(`smooth_width=1` 即为恒等, 已有测试守住)。

## 8. 功能面对照、逐项回答, 与后续路线

| 能力 | native | ewtpy | 说明 |
|---|---|---|---|
| 边界策略 | **4 套**(maximum / max-min / scale-space / envelope) | 1 套(locmax, 依赖 `reg`+`lengthFilter` 平滑) | 我们可选, 四套均已可用 |
| 过渡带宽度 γ | **auto(按边界间距反推) / 显式 float** | auto(gamma 公式同源) | 已对齐 |
| 谱平滑 | **✓ 自带分支**(`Smooth`: box / gaussian, 窗宽以频点数计) | ✓(`reg`+`lengthFilter`/`sigmaFilter`) | 已对齐能力, 但我们默认关闭(见 §5.4 的代价), 且可作用于任意边界策略而不只是 locmax |
| 预处理 | **5 个分支**(no-dc / no-trend / window / Slepian-Optimize / Smooth) | ✗(`TODO Preprocessing steps not yet implemented`) | 我们独有 |
| 镜像延拓 | ✓ `mirror=True/False` | ✓ 恒开启(2N−1 轴) | 等价能力 |
| 自动模式数 | ✓(`envelope` 分支) | ✓(`completion`) | `completion` 我们未实现 |
| 归一化选项 | 2 / None / approximate | 2 / approximate / **subsample** | `subsample` 仅 scipy 后端支持 |
| 大数组 | ✓ 分块 + memmap 可选 | ✗ | 见 `EWT_CHUNK_WORK_BYTES`/`BIG_ARRAY` |
| 结果契约 | ✓ `DecompositionResult`(IMFs/Res/info/config 快照) | 裸 tuple | 与全库一致 |
| 依赖 | 无 ewtpy(`EWT` 自研) | — | `Operator/` 自研滤波器组; ewtpy 只出现在可选入口 `EWTpy` |
| ewtpy 接入 | **✓ 可选适配层 `EWTpy`** | — | 注册键 `"EWTpy"` 与 `"EWT"` 并列; `cache.import_module` 惰性导入, 缺库只影响该入口(§1 第 10 项) |
| Slepian 后端 | ✓ numpy/scipy/C + 缓存 | — | 见 Slepian 两份报告 |

**回答"是否全面更好"**: **能力面已经全面覆盖, 默认配置下只在"个别信号的边界定位精度"上略逊 —— 而这一项现在可以用一个可选开关抹平**。

- **已更好**: 重构契约(恒精确)、带和保真(6/8 反超; 修复前 1/8)、紧框架质量(**全轴** 2.2e-16, 而 ewtpy 有 2.2%–33.8% 的频点破缺)、速度(14–29×)、内存(−40%)、退化输入鲁棒性、功能广度、库内集成、依赖面。capture 在 multitone 上大幅领先(0.967 vs 0.540), bearing 的"分错带"问题已随 auto γ 消失。
- **默认配置下仍略逊**: ① 个别信号的边界定位精度(close_tones capture 0.985 vs 0.999; bearing 匹配距离 99.95 vs 25.05 Hz、稳定性 0.96 vs 0.12 Hz)—— 开 `pre_deal="Smooth"` 后匹配距离 99.95→75.05 Hz、capture 0.967→0.991, 但稳定性从 0.67 Hz 退到 2.4 Hz(§5.4), 即"换来 ewtpy 的准度也换来 ewtpy 的抖动"; ② `log` 对数谱 / `completion` 自动模式数收尾 / `subsample` 参数未实现。

**后续路线(按性价比排序)**:

1. ~~**自动 `band_factor`**~~ —— **已落实**(§2.2), 并设为默认; 显式 float 保持旧行为。
2. ~~**修 `envelope` 分支**~~ —— **已落实**(§1 第 6 项), 由 1 带恢复为 5 带且边界合理。
3. ~~**最高带拉平到 Nyquist**~~ —— **已落实**(§1 第 7 项 / §2.3), 全轴紧框架 `ΣH² ≡ 1`。
4. ~~**补谱平滑**~~ —— **已落实为可选分支**(§1 第 8 项 / §5.4), 默认关闭。
5. ~~**切换入口**~~ —— **已落实**(§1 第 9/10 项): 自研实现迁入 `EWT.py` 并持有注册键 `"EWT"`; 原 ewtpy 包装版改为可选适配层 `EWTpy.py`(注册键 `"EWTpy"`), ewtpy 降级为可选依赖(经 `cache.import_module` 惰性导入)。`Class.EWT` 与 `Function.EWT` 现在即自研实现, 与 ewtpy 可并列对照。
