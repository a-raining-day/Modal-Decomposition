> 本文由 5 路只读调研合并而成：架构实现、算法与探索、Base+Utils、测试文档治理、Word 报告交叉核对。

## 0 一句话定位

**15 种模态分解算法（EMD 家族 6 + 频域 3 + 变分 2 + 滤波 2 + SSA/MEMD）收进一套统一契约**，
以 Apache-2.0 开源、PyPI 分发，自带可重跑的基准与 1500+ 项测试；核心竞争力不是"又一个算法"，
而是**统一契约 + 可复核基准**这层基础设施。

## 2 架构（五层 + 依赖偏序）

```
用户 API      __init__.py: Class / Function / set_seed；各文件尾部 f_*
契约层        Define/：ClassDefine(Decomposer/DecompositionResult) / ConfigDefine /
              ConstDefine / TextDefine / PathDefine
算法层        15 个顶层 *.py，各自 XxxConfig + Xxx + f_Xxx
基础设施      Base/：Cache / CPU / Memory / Chunk / Seed
工具层        Utils/：Check / Peaks / Poly / Envelope / Hilbert / Mirror /
              Slepian / Monotonicity + Operator/
加速层        Utils/_Hilbert（Cython+C）、Utils/_Slepian/_C（纯 C + ctypes）
```

- **依赖偏序**：`Base/__init__.py:4` 明示 `Define < Base < Utils`，实测无反向 import。
- **校验链五段**：`__init__` 白名单 → `param_check` → `check_output_memmap`（`decompose` 首句）
  → `Check_Time_and_Signal`（在 `Utils/Check.py:403`，**不在 Define/**）→ `finalize_output`（末句）。
- **残差语义并不统一**（必须文档化）：EMD 族=剥减余量；EFD/CEEFD=`S−ΣIMFs+mean`；
  FMD=输入副本；SSA/VMD=`None`。`Res` 字段统一存在，语义按算法不同。
- **memmap**：`output_memmap` 必须是最后一个形参且默认 `False`（`tests/test_memmap_output.py:102` 强制）；
  为 `True` 时 `IMFs/Res/info` 中 ndim>0 的数组全部转 memmap，由 `Memory.temp_memmap` 登记、`atexit` 清理。

## 3 基础设施要点

| 模块 | 职责 | 关键约定 |
|---|---|---|
| Cache | 全库唯一惰性 import 入口 | 永不覆盖 + 负缓存；命中路径无锁 112 ns（原 315 ns） |
| CPU | 可分配核数 | `total_cpu` / `set_allocable`（int=核数，-1=全部，float=比例），默认 2/3 |
| Memory | 预算与临时映射 | `budget=min(avail(1−r), commit(1−r)·0.6)−extras`，r=0.25；幂等清理、Windows 先关句柄 |
| Chunk | 分块 | **入参字节、返回元素**；`min(nbytes,0.75·budget)//itemsize`；exo 块由 temp_memmap 持有 |
| Seed | 两级种子 | 全局 `GLOBAL_SEED(42)` > 实例 seed；`temporary_seed` 写类属性（原写实例属性→no-op） |

## 4 十五个算法（原理 / 复杂度 / 默认）

| 算法 | 原理一句话 | 复杂度 | 关键默认 |
|---|---|---|---|
| EMD | 极值镜像延拓 + 三次样条包络筛分 | O(K·I·N) | `num_imf=-1, nbsym=4, internal_iter=50, faster=True` |
| EEMD | 加 M 组白噪声各做 EMD 再平均 | O(M·K·I·N) | `noise_amp=0.3·std, M=50` |
| CEEMD | 正负互补噪声对 2M 次 EMD | O(2M·K·I·N) | `noise_amp=0.3, M=25` |
| CEEMDAN | 每阶只做单阶 EMD，逐阶剥残差 | O(M·K·I·N) | `noise_amp=0.3, M=50` |
| ICEEMDAN | 局部均值算子残差差分 | O(M·K·I·N) | `noise_amp=0.2, M=100` |
| RPSEMD | 极值点瞬时频率聚类 + 相位平均 | O(K·I·N+P²logP) | `num_imf=10, sin_smaple_num=4` |
| EFD | 幅值谱分段 + 每带半谱 irfft | O(N log N) | `max_IMFs=-1` |
| CEEFD | 循环包络迭代后再 EFD | O(iter·N log N) | `envelop_iter=3` |
| EWT | 谱分割 + Meyer 小波滤波器组 | O(N log N+K·N) | `num_imfs=8` |
| VMD | ADMM 频域交替更新 | O(n·K·N log N) | `num_imf=2, n=500, alpha=2000` |
| SVMD | 逐模态 VMD | O(K·max_iter·N log N) | `num_modes=3, max_iter=500` |
| LMD | 滑动平均求局部均值/包络 | O(K·I·N) | `max_iter=37, eps=0.05, hilbert_mod=scipy` |
| FMD | 相关峭度目标 FIR + 广义特征分解 | O(K·iter·(L²N+L³)) | `K=10, L_factor=2, solver=ck` |
| SSA | 轨迹矩阵 SVD + 对角平均 | O(N·L²) 内存 O(N·L) | `window_size=N//3, energy_frac=0.995` |
| MEMD | 多方向投影筛分 | O(K·I·N·d) | `sd_thresh=0.2, max_iter=10` |
