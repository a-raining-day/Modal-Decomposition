## 小结

- **CubicSpline/sd0.01 (默认)**: 快约 PyEMD 1.1-1.5x / PySDKit 1.2-1.6x; corr_hi 0.9968-0.9969, corr_lo 0.9965-0.9967。
- **linear/sd0.01 (速度档)**: 快约 PyEMD 1.9-6.6x / PySDKit 2.0-7.3x; corr_hi 0.9943-0.9945, corr_lo 0.9935-0.9939。
- 默认档 (CubicSpline/sd0.01) 与 PyEMD/PySDKit 同包络语义, 双音调 corr 同档 (~±0.01); linear 速度档为速度-质量权衡的另一端 (详见 docs/EMD_Validation_and_Comparison_Report.md 的模式级验证)。
- 三方 IMF 行数与模式数相当; 重构误差: 库 EMD ~1e-16 (逐次减法保证), PyEMD / PySDKit ~0 (引擎自带对角平均)。
